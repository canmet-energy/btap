# NECB coverage reference attribution

The cached article excerpts are from the National Energy Code of Canada for Buildings
(NECB), 2020 and 2025 editions.

This notice covers **all cached NECB text and table content in this
distribution**, wherever it sits: each edition's
`coverage/articles_8_4.json`, and the archived source payloads retained under
each edition's `provenance/` directory — the canonical building-codes MCP
results that the manifest's `provenance` block hashes, so a reader can
re-establish where a shipped rule file or table came from.
